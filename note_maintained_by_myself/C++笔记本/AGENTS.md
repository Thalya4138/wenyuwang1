## 四、编译与实跑（本机已实测可用）

编译环境**不在 PATH 里**，必须先用 `vcvars64.bat` 初始化：

```powershell
# PowerShell 里编译并运行一个块
$vcvars = "C:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools\VC\Auxiliary\Build\vcvars64.bat"
cmd /c "`"$vcvars`" >nul 2>&1 && cd /d <工作目录> && cl /nologo /std:c++17 /EHsc /W4 /utf-8 main.cpp /Fe:main.exe && main.exe"
```

- **`/utf-8` 别省**：本机控制台活动代码页是 **936（GBK）**，不加它，源码里的中文和输出会乱码。
- **`/W4` 别省**：很多"能编过但错了"的写法只有警告会提醒你。
- 判题机/竞赛写法要额外说明，因为 OJ 多用 GCC，且常关警告。

## 五、代码块标记约定（与 `tmp/verify_cpp.py` 配套）

```markdown
<!-- example:hello -->
```cpp
#include <iostream>
int main() { std::cout << 7 << '\n'; }
```

<!-- result:hello -->
```text
7
```
```

- 每个示例用 `<!-- example:唯一键 -->` 起头，紧跟一个 ` ```cpp ` 块。键在**全章唯一**。
- 预期输出放 `<!-- result:键 -->` 的 ` ```text ` 块里，**逐字全等**比对。
- 输出里含随环境变化的内容（如 `argv[0]` 的完整路径）时，改用 `<!-- run-expect:键 -->`（**前缀匹配**）。
- 故意编译失败的示例用 ` ```cpp compile-fail `，脚本只断言"编译失败"，不比输出。
- **需要 stdin 的示例**用 `<!-- stdin:键 -->` 给出输入内容。

> ⚠️ **不要给所有代码块都加标记。** 片段、伪代码、汇编清单、诊断文本、
> 需要多个 `.cpp` 的例子**一律不加**——加错标记会在验收基线里制造假失败。
>
> **判据**：*这一段能不能单独存成一个 `main.cpp`，编译后得到确定的输出？* 能 → 加；不能 → 不加。

**验证命令**：

```powershell
python tmp/verify_cpp.py "note_maintained_by_myself/C++笔记本" -v
```

> ⚠️ **判据是「块数 > 0 且不符合 0」，不是「不符合 0」。**
> 标记写错时脚本会扫到 **0 块**并报"0 处不符合"——那是**静默假通过**。
> 本项目已真实发生过一次（第 1 章初稿 53 个代码块、0 个进基线）。

## 八、结构层规范（最容易被忽略、也最影响质量）

- **同一级标题只能属于同一个分类轴。** 入口 / 共用规则 / 独有能力 / 机制 / 用途 / 特例 / 进阶不能混层。
- **先讲概念之间的关系，再分别展开**；相似概念先给对比表，不要并列写四段定义。
- **先具体执行过程，再抽象规则**：最小例子 → 执行过程 → 规律 → 语法 → 一般形式 → 边界 → 比较 → 机制 → 进阶。
- **章首给地图**（位置、前置、解决什么问题、分几部分、学完具备什么能力）；
  **章末是「知识结构回收」**，不是"本章总结"。
- 写正文前自检：**只看目录，能不能看懂这个主题的知识结构？** 不能就先改目录。

## 九、C++ 特有的分层要求（这几组最容易混层，写之前先想清楚）

C++ 的坑大多来自"看起来等价"。这几组必须**主动给对比表**，且不能混在一段里：

| 组 | 必须讲清的区别 |
|---|---|
| 初始化 | 默认初始化 / 值初始化 / 直接初始化 / 拷贝初始化 / 列表初始化，以及 `{}` 的窄化检查 |
| 声明 vs 定义 | 声明、定义、ODR、`inline`/`static`/`extern` 链接性、翻译单元 |
| 引用 vs 指针 | 是否可空、是否可重绑定、语法、底层实现、什么时候用哪个 |
| 值类别 | 左值/右值/将亡值 → 移动语义 → 拷贝省略（这是入门材料最容易整段漏掉的） |
| `const` | `const` 对象 / `const` 引用 / 顶层 vs 底层 const / `const` 成员函数 / `constexpr` |
| 编译期 vs 运行期 | `constexpr`、`if constexpr`、模板实例化、静态断言 |
| 未定义行为 | 不是"结果随机"，而是**程序已失去任何保证**；要说清哪一类错 |
