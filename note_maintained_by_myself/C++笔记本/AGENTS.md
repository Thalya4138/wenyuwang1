# C++ 讲义 · Agent 专项入口

适用于本目录 C++17 正式讲义维护；C++20/23 必须明确标注版本与验证范围。
全局和仓库入口只路由，所链接正文须显式读取。

## 开工顺序

1. [`_handoff/RUN-STATE.md`](_handoff/RUN-STATE.md)：当前任务、模式、允许范围和冻结快照。
2. [`../../笔记与讲义整理规范.md`](../../笔记与讲义整理规范.md)：通用正式源。
3. [`_写作规范.md`](_写作规范.md)：C++ 标记、目录、自测、覆盖对账、诚实标注。
4. [`_维护须知.md`](_维护须知.md)：环境核对、命令、验证器与历史陷阱。
5. 写章时读 [`_章节施工图.md`](_章节施工图.md)；涉及多人协作再读 [`_协作规范.md`](_协作规范.md)。
6. [`00_知识点总览.md`](00_知识点总览.md)、[`01a_三源交叉核对.md`](01a_三源交叉核对.md) 与获准修改的正文。

## 最小执行要求

- 输出及诊断实际采集；语言语义用对应版本依据，实跑不能证明没有 UB。
- 示例按独立程序、片段、多文件、交互、故意失败、UB 等分类验证。
- `result` 全等；`run-expect` 仅断言足以支持主张的非空稳定前缀。另行核对退出状态。
- 文件数量、代码块数量、匹配/预期失败/无预期/跳过/超时分别报告，零扫描不算通过。
- 章首目录、章末自测、覆盖对账及诚实标注保持一致；跨章引用用真实标题及节号。
- 不编输出、不谎报、不偷偷丢内容；自主解释自己写，指定底稿按通用规范保真。
- 单轮单文件一个写入者，保护冻结范围及既有成果。临时文件放仓库根 `tmp/`。
- 用户明确的新任务优先于旧状态；先记录替换原因并更新状态，不重新执行已完成任务。
- 提交、推送按用户明确授权范围；未授权不执行。

Python 的 [`../_AI维护须知.md`](../_AI维护须知.md) 和写作规范仅适用于 Python，不能借用其基线判断 C++。
