**我去核了，它完全正确。** 本机实测（**合法程序、零 UB**）：

```cpp
Noisy make() { Noisy local; return local; }   // NRVO 可省略
int main() { Noisy n = make(); }
```

| 编译选项 | 真实输出 |
|---|---|
| `/Od /Zc:nrvo-` | `ctor` / **`move`** / `dtor` / `dtor` |
| `/O2 /Zc:nrvo` | `ctor` / `dtor` |

**NRVO 是标准允许的省略**，所以同一个**良定义**程序在不同优化选项下输出可以不同。

> ~~"因为如果行为不同，那就说明有 UB"~~

**这是把充分条件当必要条件用**——"有 UB ⇒ 可能不同"成立，反过来不成立。

**它已经直接改了正文**（第 12 章第 296–297、861–862 行；第 13 章第 179、523 行），
把这条判据收窄成"先检查标准允许的省略 / 未指定 / 实现条件，再排查 UB"。

**两章回归验证**：第 12 章 **10 块全绿**、第 13 章 **6 块 + 1 块预期编译失败**、锚点 15 文件 0 问题。
