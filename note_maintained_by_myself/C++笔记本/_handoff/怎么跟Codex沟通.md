## 四、为什么值得再请它一次（它上一轮干了什么）

**它抓出了我自己读不出来的错误，两轮共 5 条：**

| 我写的 | 真相 |
|---|---|
| `argc` 至少是 1 | 标准只保证**非负** |
| `argv` 字符串不能改 | **可以改** |
| `#pragma` 非标准 | **是标准指令** |
| `/Zi` 时才有调试信息 | `/Z7` 也行 |
| **"不同优化级别输出不同 ⇒ 有 UB"** | **错**，NRVO 是标准允许的省略，合法程序输出也能不同 |

**最后一条最值钱**：它不是查文档能发现的**事实错误**，而是**推理错误**——我把充分条件当必要条件用了。
它直接改了正文，我实测复核后**接受它的修改**。

**这就是多一个模型视角的价值**：事实错误我自己能查，**推理错误只有换视角才看得出来**。
