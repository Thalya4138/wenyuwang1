## 三、为什么要有这道闸（**不是形式主义**）

**上一轮真实发生过这个问题**：

Codex 在 DSH 侧**正在写第 03–11 章的时候**启动了审计，结果是：

- 它审计到的 `01`/`02`/`06`/`12`/`13` 是当时的状态，而这几章**随后又被改过**
- 它的报告里有一节是"对 A 实测结论的复核"，但**A 的实测结论在同一时间还在更新**
- 更麻烦的是：**它还没来得及审计的章节（03–05、09–11）当时根本不存在**

**代价**：报告的一部分注定要返工——不是因为 Codex 做错了，而是因为**审计的对象还在动**。

> **判据**：**审计必须针对一个冻结的快照。**
> 如果被审计的文件在审计期间还在变，"你审的是哪一版"就成了无法回答的问题。
