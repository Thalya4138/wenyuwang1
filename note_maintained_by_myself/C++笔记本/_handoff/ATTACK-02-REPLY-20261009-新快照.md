# ATTACK-02-REPLY：2026-10-09 新快照

本轮最危险的心智模型是第 03 章第 2 节的“有名字就是左值、没名字就是纯右值”。它把表达式的语义分类误教成变量命名规则：`*p` 与字符串字面量没有变量名形式却都是左值，返回对象右值引用的函数调用是将亡值；`std::move(x)` 既不使 x 马上失效，也不保证已经发生移动。这个模型又被“将亡值能取地址”与“decltype 分不清将亡值/纯右值”强化，读者会写出不合法的 `&std::move(x)`，或在模板中把匿名左值错误地强制移动，意外转走调用者仍需要的资源。正确做法是按表达式规则判断；排除未加括号名字/成员访问的特殊规则后，decltype 对左值给 T&、将亡值给 T&&、纯右值给 T。本轮 MSVC 独立探针验证了 `*p`、字符串字面量、对象右值引用返回调用、std::move 与纯右值的差异，输出五行 true 与 7；直接取将亡值地址得到真实 C2102。已在正文修正并加入反例，详见同轮完整报告。

依据：[C++17 decltype 规则](https://timsong-cpp.github.io/cppwp/n4659/dcl.type.simple)、[C++17 内建取地址规则](https://timsong-cpp.github.io/cppwp/n4659/expr.unary.op)。
