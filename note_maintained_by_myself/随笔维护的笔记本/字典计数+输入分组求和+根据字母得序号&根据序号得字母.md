### 2、输入数组（① 一组一组输入直至enter ② 输入若干组后自动分组）
```python
#输入数组直到输入enter
import math
x = 0
y = 0
while True:
    s = input()
    if s == "":
        break
    a, b = map(float, s.split())
    x += a
    y += b
print(f"{math.sqrt(x**2+y**2):.4}")

#把输入分组
import math
x = 0
y = 0
s = list(map(float, input().split()))
for i in range(0, len(s), 2):
    x += s[i]
    y += s[i + 1]
print(f"{math.sqrt(x**2 + y**2):.4f}")
```
### 3、根据字母得序号和根据序号得字母
①**根据字母得序号**
用 `ord()`。
如果输入：
```python
c = input()
```
比如：
```python
E
```
那么：
```python
ord(c)
```

会得到字符 `E` 的 Unicode 编码值：
```python
ord("A")  # 65ord("B")  # 66ord("C")  # 67ord("E")  # 69
```
所以字母表中的序号可以写成：
```python
n = ord(c) - ord("A") + 1
```
例如：
```python
c = "E"
n = ord(c) - ord("A") + 1# 69 - 65 + 1# = 5
```
所以完整一点：
```python
c = input()
n = ord(c) - ord("A") + 1
print(n)
```
②**根据序号得到字母**
这时候用 `chr()`。
例如：
```python
chr(65)  # 'A'chr(66)  # 'B'
```
所以如果你现在有：
```python
i = 3
```
想得到第 3 个大写字母 `C`，可以写：
```python
chr(ord("A") + i - 1)
```
也就是：
```python
ord()：字符 → 编码数字
chr()：编码数字 → 字符
```
