### 第一步：先学会判断质数

一个大于 1 的整数，如果除了 1 和自身，没有其他正因数，就是质数。

例如，我们可以写：

```Python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True
```

$$
为什么只检查到 \(\sqrt n\)？因为如果一个合数可以写成 \(n=a\times b\)，那么 \(a,b\) 不可能都大于 \(\sqrt n\)，所以至少有一个因数不超过 \(\sqrt n\)。
$$
