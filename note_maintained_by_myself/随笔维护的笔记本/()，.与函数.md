你问的其实是 Python 里一个非常核心的“语法结构问题”：

> **什么时候写 `()`？什么时候写 `.`？什么时候把东西放进前面的括号？**

这个问题本质上是在区分：

1. **调用（call）**
2. **访问（access）**
3. **传参数（argument）**
4. **链式调用（chaining）**

我们慢慢拆。

---

# 一、最核心规则：看到 `()`，先想到“执行”

比如：

```
print()
```

这里：

```
print
```

是一个函数。

```
()
```

表示：

> 调用它，让它运行。

---

例如：

```
len([1,2,3])
```

拆：

```
len
↓
函数名字

([1,2,3])
↓
给函数的输入
```

意思：

> 调用 len 函数，并把列表传进去。

---

如果没有括号：

```
len
```

它只是函数本身。

类似：

你说：

> “张三”

只是名字。

你说：

> “叫张三过来”

才是执行动作。

---

# 二、`.` 是访问，不是执行

例如：

```
a.sort()
```

拆：

```
a
↓
对象

.
↓
找到对象里面的东西

sort
↓
方法

()
↓
执行方法
```

所以：

```
a.sort()
```

意思：

> 找到列表 a 的 sort 方法，然后运行它。

---

如果：

```
a.sort
```

没有括号：

意思是：

> 拿到这个方法本身。

比如：

```
print(a.sort)
```

可能输出：

```
<built-in method sort of list object>
```

因为你只是拿到了函数，没有执行。

---

# 三、为什么有时候括号在前面，有时候在后面？

看这两个：

## 1. 函数

```
sorted(a)
```

结构：

```
函数名(参数)
```

因为：

`sorted` 是一个独立函数。

所以：

```
sorted(列表)
```

---

## 2. 方法

```
a.sort()
```

结构：

```
对象.方法(参数)
```

因为：

`sort` 属于列表对象。

所以：

```
列表.sort()
```

---

比较：

```
a = [3,1,2]sorted(a)a.sort()
```

第一个：

```
sorted
↑
Python提供的函数
```

第二个：

```
a
↓
列表对象

.sort
↓
列表自己的能力
```

---

# 四、什么时候把东西写进括号？

括号里面放：

> 这个函数/方法需要的信息。

例如：

## len

```
len(a)
```

因为 len 需要知道：

“你要计算谁的长度？”

---

## print

```
print("hello")
```

因为 print 需要知道：

“你要打印什么？”

---

## sort

```
a.sort(reverse=True)
```

因为 sort 需要知道：

“按照什么规则排序？”

---

# 五、什么时候括号里面什么都不写？

因为这个动作不需要额外信息。

例如：

```
a.sort()
```

意思：

> 用默认规则排序。

---

```
list.clear()
```

意思：

> 清空列表。

不需要告诉它清空什么，因为它已经知道自己是谁。

---

# 六、一个特别容易混淆的地方：属性 vs 方法

例如：

```
student.name
```

和：

```
student.get_name()
```

区别：

## 属性

```
student.name
```

它是一个数据。

例如：

```
student.age
```

结果：

```
18
```

所以没有括号。

---

## 方法

```
student.study()
```

它是一个动作。

所以有括号。

---

记忆：

```
属性 = 名词
方法 = 动词
```

例如：

```
学生.name
学生.age
```

是东西。

```
学生.eat()
学生.study()
```

是动作。

---

# 七、你刚才问排序函数就是一个很好例子

## sorted

```
sorted(nums)
```

因为：

```
sorted 是函数
```

所以：

```
函数(参数)
```

---

## sort

```
nums.sort()
```

因为：

```
sort 是列表的方法
```

所以：

```
对象.方法()
```

---

## key

```
sorted(nums,key=len)
```

这里：

```
key=len
```

没有括号！

为什么？

因为你传的是：

> 一个函数本身。

意思：

“以后排序时，请调用这个规则。”

不是现在调用。

---

如果写：

```
sorted(nums,key=len())
```

错误。

因为：

```
len()
```

现在就执行了。

但是现在没有告诉它对象，所以不知道算什么。

---

这个区别非常重要：

```
key=len
```

表示：

> 把函数交给别人。

---

```
key=len(...)
```

表示：

> 现在马上执行函数。

---

# 八、一个总表

|写法|含义|
|---|---|
|`func`|函数本身|
|`func()`|调用函数|
|`obj.attr`|获取对象属性|
|`obj.method`|获取方法|
|`obj.method()`|调用对象的方法|
|`func(x)`|调用函数，并传入 x|
|`func(key=value)`|给函数传参数|

---

你现在学到这里，后面**类、对象、库函数、算法题**都会反复遇到这个问题。

一个很好用的判断：

> **有没有括号，看它是不是“现在要执行”。**
> 
> **有没有点号，看它是不是“某个对象拥有的能力”。**
> 
> **括号里面写什么，看这个动作需要什么输入。**

这三个判断基本能解决 Python 里 80% 的括号迷惑。
