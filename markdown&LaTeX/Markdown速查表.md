# Markdown 完全速查表（对照视频 BV1JA411h7Gw 补全）

> 用法：左边是**你打的原文**，右边是**渲染效果**。
> 逻辑按视频的两条主线分：**块级元素**（独占一行）和 **行内元素**（插在文字中间）。

---

## 〇、先记住这条主线（视频的分类法）

Markdown 的符号分两类，**用错地方就不生效**：

| 类别 | 特点 | 包含 |
| --- | --- | --- |
| **块级元素** | 自己**独占一行**（或一整块） | 标题、引用、列表、代码块、公式、表格、脚注、横线 |
| **行内元素** | **插在文字中间**，不换行 | 链接、图片、加粗、斜体、行内代码、行内公式、上下标、高亮、emoji |

> 判断方法：这个符号是**管一整段**的，还是**只管几个字**的。

## 一、5 分钟上手（先记这 5 个）

### 1. 标题 `#`

```
# 一级标题（最大）
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题（最小）
```

# 一级标题（最大）
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题（最小）

> **共 6 级**，`#` 越多字越小。`#` 后面**必须有一个空格**。

### 2. 加粗 / 斜体 / 删除线

```
**加粗**    *斜体*    ~~删除线~~
```

**加粗**　*斜体*　~~删除线~~

### 3. 列表

```
- 无序列表用短杠
* 星号也行
1. 有序列表用「数字.空格」
```

- 无序列表用短杠
* 星号也行

1. 有序列表用「数字.空格」

> 有序列表的数字可以全写 `1.`，渲染时自动编号。

### 4. 换行与空行（新手最大坑）

- 敲**一次回车 = 没换行**，两行会挤在一行。
- 要换行：**行尾敲两个空格**再回车，或**直接空一行**（变成新段落）。
- 最稳的习惯：**段落之间永远空一行**。

### 5. 段落与引用

```
> 大于号表示引用
>> 可以嵌套
```

> 大于号表示引用
>> 可以嵌套

## 二、块级元素（独占一行）—— 共 8 个

### 1. 标题

见上面第一节。补充：还有「下划线式」写法（**很少用**，知道就行）

```
一级标题
========

二级标题
--------
```

### 2. 引用 `>`

```
> 这是一段引用
>
> 引用里可以放空行继续写
```

> 这是一段引用
>
> 引用里可以放空行继续写

### 3. 列表（三种）

**① 有序列表**

```
1. 打开冰箱
2. 把大象塞进去
3. 关闭冰箱
```

1. 打开冰箱
2. 把大象塞进去
3. 关闭冰箱

**② 无序列表**（`-` 或 `*` 都行）

```
- 小明
- 小红
  - 缩进两格 = 子条目
```

- 小明
- 小红
  - 缩进两格 = 子条目

**③ 任务列表**（待办清单）

```
- [ ] 没做的事
- [x] 做完的事
```

- [ ] 没做的事
- [x] 做完的事

> 方括号里**空格 = 未完成**，**x = 已完成**。

### 4. 代码块

````
```python
import torch
```
````

```python
import torch
```

> 开头三个反引号，**紧跟语言名**（`python` / `cpp` / `java`…），结尾再来三个反引号。
> 反引号键在 **Esc 下面**、数字 1 左边。
> 不写语言名也能跑，只是没有语法高亮。

### 5. 数学公式（LaTeX 格式）

```
行内公式：$E = mc^2$
独占一行：$$\frac{\partial f}{\partial x} = 2\sqrt{a}x$$
```

行内公式：$E = mc^2$

独占一行：

$$\frac{\partial f}{\partial x} = 2\sqrt{a}x$$

> 公式内容用 **LaTeX 语法**，详细写法见同目录 `LaTeX速查表.md`。

### 6. 表格（三部分：表头 / 对齐 / 内容）

```
| 左对齐 | 右对齐 | 居中对齐 |
| :--- | ---: | :---: |
| ss | sas | sfaf |
| bb | ccc | aaa |
```

| 左对齐 | 右对齐 | 居中对齐 |
| :--- | ---: | :---: |
| ss | sas | sfaf |
| bb | ccc | aaa |

> 三行结构：**第一行表头 → 第二行对齐 → 之后是内容**。
> 对齐就是看冒号 `:` 在哪边：`:` 在左 = 左对齐，在右 = 右对齐，两边都有 = 居中。
> **第二行必须有**，短横线数量不限。

### 7. 脚注 `[^名字]`

```
Markdown 很好用[^1]。

[^1]: 这是脚注内容，会显示在文章最底部。
```

Markdown 很好用[^1]。

[^1]: 这是脚注内容，会显示在文章最底部。

> 点那个小数字会跳到文末说明。**两处名字要一致**（`[^1]` 和 `[^1]:`）。

### 8. 横线（分割线）

三种写法**效果一样**，任选：

```
---
***
___
```

---
***
___

> 推荐 `---`。**注意**：`---` 上一行如果紧挨着文字，有可能会把它变成「二级标题」而不是横线——**上面空一行**就没事。

## 三、行内元素（插在文字中间）—— 共 7 个

### 9. 链接

**① 普通链接**

```
[百度](https://baidu.com)
[百度](https://baidu.com "鼠标指向才显示的描述")
```

[百度](https://baidu.com)　[百度](https://baidu.com "鼠标指向才显示的描述")

> 引号里那段叫 **title**，鼠标悬停才显示，可写可不写。

**② 引用链接**（同一个地址用很多次时，改一处就全改）

```
[百度][id] 和 [百度][id] 都用同一个地址

[id]: https://baidu.com "一个搜索引擎"
```

[百度][id] 和 [百度][id] 都用同一个地址

[id]: https://baidu.com "一个搜索引擎"

**③ 标题跳转（锚点）**

```
[跳到「块级元素」](#二块级元素独占一行-共-8-个)
```

> 规则：`#` 后写标题文字，**空格换成短横线**、**去掉标点**、**英文转小写**。
> 中文有时会失灵（视频作者也吐槽过），失灵的替代办法是写 URL 编码，如 `#%E5%89%8D%E8%A8%80`。

**④ 裸 URL**

```
<https://www.baidu.com>
```

<https://www.baidu.com>

> 用尖括号包住，才会变成可点的链接；不包的话很多编辑器不认。

### 10. 图片

```
![图片名](图片地址)
![图片名](图片地址 "图片描述")
```

> 和链接**只差一个 `!`**。图片地址可以是网址，也可以是本地同级目录的文件名（如 `图1.png`）。
> 在 CSDN、Typora 里通常**直接拖进去或粘贴**就行，不用手写。
> 地址写错时，显示的是方括号里的「图片名」。

### 11. 加粗 / 斜体 / 删除线

| 打这个 | 效果 | 快捷键（Typora/VSCode） |
| --- | --- | --- |
| `*斜体*` | *斜体* | `Ctrl + I` |
| `**加粗**` | **加粗** | `Ctrl + B` |
| `***加粗斜体***` | ***加粗斜体*** | 两个一起按 |
| `~~删除线~~` | ~~删除线~~ | 无 |

### 12. 行内代码

```
用 `Ctrl + C` 复制。
```

用 `Ctrl + C` 复制。

> 一对反引号包住**几个字**；三个反引号那是「代码块」，占一整行。

### 13. 转义字符 `\`

想在文字里**显示符号本身**，不被当成语法，就在前面加反斜杠：

```
\* 这不是斜体
\# 这不是标题
\_ 这不是下划线
```

\* 这不是斜体
\# 这不是标题
\_ 这不是下划线

### 14. 行内公式

```
质能方程 $E = mc^2$ 很简洁。
```

质能方程 $E = mc^2$ 很简洁。

### 15. emoji 表情

```
今天很开心 :smile:
```

今天很开心 :smile:

> 冒号 + 英文名 + 冒号。**只在部分平台生效**（CSDN、Typora、GitHub 可以）。
> 直接打输入法的 emoji 😄 最保险，到处都能显示。

## 四、扩展语法（⚠️ 不一定能用，看编辑器）

下面这些**不是标准 Markdown**，是 Typora / CSDN / Obsidian 等自己加的。**在 VSCode 预览或 GitHub 上可能不生效**，用之前先试。

| 功能 | 打这个 | 效果 | 哪儿能用 |
| --- | --- | --- | --- |
| 下划线 | `<u>下划线</u>` | <u>下划线</u> | 支持 HTML 的地方 |
| 下标 | `H~2~O` | H~2~O | Typora、CSDN |
| 上标 | `X^2^` | X^2^ | Typora、CSDN |
| 高亮 | `==高亮文字==` | ==高亮文字== | Obsidian、Typora、CSDN |
| 目录 | `[TOC]` | 自动生成全文章节目录 | Typora、CSDN、博客园 |
| 折叠块 | `<details><summary>点开</summary>内容</details>` | 可折叠 | GitHub、支持 HTML 的地方 |
| 流程图 | ` ```mermaid ` 代码块 | 自动画流程图/UML | GitHub、Typora、Obsidian |
